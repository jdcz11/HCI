# Pokémon News

## Overview

Pokémon News is a web-based project designed to provide the latest updates, news, and information about Pokémon. It features a carousel for new Pokémon, a news section, a Pokédex, and a contact form. The project is implemented using HTML, CSS, and JavaScript.

## Project Structure

- **.vscode**: Contains VS Code settings.
- **images**: Contains image assets for the project.
- **scripts**: Contains JavaScript files for various functionalities.
- **styles**: Contains CSS files for styling.
- **index.html**: Main HTML file for the homepage.
- **pokedex.html**: HTML file for the Pokédex section.

## Features

- **Responsive Design**: Ensures compatibility across various devices.
- **Interactive Carousel**: Displays new Pokémon with navigation buttons.
- **News Section**: Contains articles about the latest Pokémon updates.
- **Pokédex:**: CProvides information about different Pokémon.
- **Contact Form:**: Allows users to send messages and contact the project owner.
- **Theme Toggle**: Users can switch between light and dark themes.
